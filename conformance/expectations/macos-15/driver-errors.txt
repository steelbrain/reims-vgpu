# Direct indexed draw semantics. Both index widths and byte offsets match the
# shared-shader control when baseVertex is zero. Either width fails only when
# the signed base is -1, so the driver loses or misapplies baseVertex. General
# non-indexed baseInstance passes; only the indexed base-instance opcode is
# accepted without an executor and produces no pixels.
draw_indexed_uint16_base_vertex_minus1 # signed baseVertex is lost or misapplied
draw_indexed_uint32_offset_4_base_vertex_minus1 # signed baseVertex is lost or misapplied
draw_indexed_two_instances_base_instance_5 # indexed base-instance opcode accepted without executor
